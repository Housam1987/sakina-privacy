🇩🇪 Datenschutzerklärung

Zusammenfassung: Sakina ist eine Offline-First-App. Alle Daten werden primär lokal auf deinem Gerät gespeichert. Zusätzlich nutzen wir Firebase-Dienste von Google für Absturzberichte, anonyme Nutzungsstatistiken und optionale Cloud-Sicherung. Es gibt keine Werbung, keine personalisierte Datenerhebung und keinen Verkauf von Daten an Dritte. Die App funktioniert vollständig ohne Internetverbindung.

1. Lokale Datenspeicherung

Sakina speichert folgende Daten lokal auf deinem Gerät (SharedPreferences):

  • Dein gewählter Anzeigename (für die persönliche Begrüßung)
  • Spracheinstellung (Deutsch, Englisch oder Arabisch)
  • Tagebucheinträge aus den Coaching-Sitzungen
  • Sitzungsverlauf (welche Protokolle abgeschlossen wurden)
  • Sabr-Training Fortschritt und Streak
  • Tafakkur-Meditations-Fortschritt
  • Gewählte Hintergrundgeräusche-Einstellung
  • Benachrichtigungs-Einstellung

Diese lokalen Daten sind die primäre Datenquelle. Die App funktioniert vollständig offline.

2. Firebase Analytics

Sakina nutzt Google Analytics for Firebase zur anonymen Erfassung von Nutzungsstatistiken:

  • Welche Emotionen gewählt werden (z.B. „Traurig", „Gestresst")
  • Ob Sitzungen gestartet und abgeschlossen werden
  • Dauer der Coaching-Sitzungen
  • Nutzung von Tafakkur, Sabr-Training und Tagebuch
  • Gewählte Sprache und Hintergrundgeräusche

Zweck: Verständnis der App-Nutzung zur Verbesserung der Inhalte und Funktionen.

Keine persönlichen Inhalte (z.B. Tagebucheinträge oder Namen) werden an Analytics gesendet.

Weitere Informationen: Google Datenschutzerklärung

3. Firebase Crashlytics

Sakina nutzt Firebase Crashlytics zur automatischen Erfassung von Absturzberichten:

  • Gerätetyp und Betriebssystem-Version
  • Technische Absturz-Logs (Stack Traces)
  • App-Version und Build-Nummer

Zweck: Erkennung und Behebung von App-Fehlern zur Verbesserung der Stabilität.

Es werden keine persönlichen Inhalte (Tagebucheinträge, Namen, Gebete) in Absturzberichten erfasst.

4. Firebase Authentication

Sakina nutzt anonyme Authentifizierung über Firebase:

  • Beim ersten Start wird automatisch eine anonyme Benutzer-ID erstellt
  • Keine persönlichen Daten sind nötig — kein Name, keine E-Mail, kein Passwort
  • Die anonyme ID dient ausschließlich der Zuordnung von Cloud-Daten
  • Optional: Du kannst später eine E-Mail-Adresse hinterlegen, um deine Daten geräteübergreifend zu synchronisieren (freiwillig)

5. Cloud Firestore (Optionale Cloud-Sicherung)

Zusätzlich zur lokalen Speicherung werden folgende Daten verschlüsselt in der Cloud (Google Cloud Firestore) gesichert:

  • Sitzungsverlauf (Protokoll-ID, Emotion, Dauer)
  • Tagebucheinträge (Emotion, Prompt, Text)
  • Fortschritt (Gesamtsitzungen, Streak, Emotionsverteilung)
  • Profildaten (Name, Spracheinstellung)

Speicherort: Google Cloud, EU-Region.

Zugriff: Nur du hast Zugriff auf deine Daten (gesichert durch Firebase Security Rules).

Tagebucheinträge werden nicht analysiert oder ausgewertet — sie dienen ausschließlich der persönlichen Dokumentation.

Die App funktioniert vollständig ohne Cloud-Verbindung. Firestore ist ein zusätzliches Backup.

6. Keine Werbung

Sakina enthält keine Werbung und keine Werbe-SDKs. Daten werden nicht an Dritte verkauft.

7. Datensicherheit

Lokale Daten werden in SharedPreferences auf deinem Gerät gespeichert. Cloud-Daten werden verschlüsselt übertragen (TLS) und in Google Cloud Firestore mit Firebase Security Rules geschützt. Nur authentifizierte Nutzer können ihre eigenen Daten lesen und schreiben.

8. Kinder

Sakina erhebt wissentlich keine Daten von Kindern unter 13 Jahren. Die App enthält keine Registrierung, keine In-App-Käufe und keine Werbung.

9. Deine Rechte

Du kannst jederzeit:

  • Alle lokalen Daten über Einstellungen → Daten zurücksetzen löschen
  • Die App deinstallieren (entfernt alle lokalen Daten)
  • Löschung deiner Cloud-Daten per E-Mail anfordern (siehe Kontakt)

10. Änderungen

Bei wesentlichen Änderungen an dieser Datenschutzerklärung werden Nutzer durch ein App-Update informiert. Die aktuelle Version ist immer unter dieser URL verfügbar.

🇬🇧 Privacy Policy

Summary: Sakina is an offline-first app. All data is primarily stored locally on your device. We additionally use Google's Firebase services for crash reporting, anonymous usage analytics, and optional cloud backup. There is no advertising, no personalized data collection, and no selling of data to third parties. The app works fully without an internet connection.

1. Local Data Storage

Sakina stores the following data locally on your device (SharedPreferences):

  • Your chosen display name (for personalized greeting)
  • Language preference (German, English, or Arabic)
  • Journal entries from coaching sessions
  • Session history (completed protocols)
  • Sabr Training progress and streak
  • Tafakkur meditation progress
  • Ambient sound preference
  • Notification setting

This local data is the primary data source. The app works fully offline.

2. Firebase Analytics

Sakina uses Google Analytics for Firebase to collect anonymous usage statistics:

  • Which emotions are selected (e.g. "Sad", "Stressed")
  • Whether sessions are started and completed
  • Duration of coaching sessions
  • Usage of Tafakkur, Sabr Training, and Journal
  • Selected language and ambient sound

Purpose: Understanding app usage to improve content and features.

No personal content (e.g. journal entries or names) is sent to Analytics.

More information: Google Privacy Policy

3. Firebase Crashlytics

Sakina uses Firebase Crashlytics for automatic crash reporting:

  • Device type and operating system version
  • Technical crash logs (stack traces)
  • App version and build number

Purpose: Detecting and fixing app errors to improve stability.

No personal content (journal entries, names, prayers) is included in crash reports.

4. Firebase Authentication

Sakina uses anonymous authentication via Firebase:

  • An anonymous user ID is automatically created on first launch
  • No personal data is required — no name, no email, no password
  • The anonymous ID is used solely to associate cloud data
  • Optional: You can later add an email address to sync your data across devices (voluntary)

5. Cloud Firestore (Optional Cloud Backup)

In addition to local storage, the following data is securely backed up in the cloud (Google Cloud Firestore):

  • Session history (protocol ID, emotion, duration)
  • Journal entries (emotion, prompt, text)
  • Progress (total sessions, streak, emotion distribution)
  • Profile data (name, language setting)

Storage location: Google Cloud, EU region.

Access: Only you have access to your data (secured by Firebase Security Rules).

Journal entries are not analyzed or evaluated — they serve solely for personal documentation.

The app works fully without a cloud connection. Firestore is an additional backup.

6. No Advertising

Sakina contains no advertising and no advertising SDKs. Data is not sold to third parties.

7. Data Security

Local data is stored in SharedPreferences on your device. Cloud data is transmitted encrypted (TLS) and protected in Google Cloud Firestore with Firebase Security Rules. Only authenticated users can read and write their own data.

8. Children's Privacy

Sakina does not knowingly collect data from children under 13. The app contains no registration, no in-app purchases, and no advertising.

9. Your Rights

You can at any time:

  • Delete all local data via Settings → Reset Data
  • Uninstall the app (removes all local data)
  • Request deletion of your cloud data by email (see Contact)

10. Changes

If significant changes are made to this Privacy Policy, users will be notified through an app update. The current version is always available at this URL.

11. Contact

🇸🇦 سياسة الخصوصية

ملخص: سكينة تطبيق يعمل بالأساس بدون إنترنت. جميع البيانات تُخزَّن أولاً على جهازك محلياً. بالإضافة لذلك، نستخدم خدمات Firebase من Google لتقارير الأعطال وإحصائيات الاستخدام المجهولة والنسخ الاحتياطي السحابي الاختياري. لا توجد إعلانات، ولا جمع بيانات شخصية، ولا بيع للبيانات لأطراف ثالثة. التطبيق يعمل بالكامل بدون اتصال بالإنترنت.

١. التخزين المحلي للبيانات

يُخزّن تطبيق سكينة البيانات التالية محلياً على جهازك:

  • اسم العرض الذي اخترته (للتحية الشخصية)
  • تفضيل اللغة (الألمانية أو الإنجليزية أو العربية)
  • إدخالات اليوميات من جلسات التوجيه
  • سجل الجلسات (البروتوكولات المُكتملة)
  • تقدم تدريب الصبر والسلسلة
  • تقدم تأمل التفكّر
  • إعداد الأصوات الخلفية
  • إعداد الإشعارات

هذه البيانات المحلية هي المصدر الأساسي. التطبيق يعمل بالكامل بدون إنترنت.

٢. Firebase Analytics (تحليلات الاستخدام)

يستخدم سكينة Google Analytics for Firebase لجمع إحصائيات استخدام مجهولة:

  • المشاعر التي يتم اختيارها (مثل: "حزين"، "متوتر")
  • بدء الجلسات وإكمالها
  • مدة جلسات التوجيه
  • استخدام التفكّر وتدريب الصبر واليوميات
  • اللغة المختارة والأصوات الخلفية

الغرض: فهم كيفية استخدام التطبيق لتحسين المحتوى والميزات.

لا يتم إرسال أي محتوى شخصي (مثل إدخالات اليوميات أو الأسماء) إلى التحليلات.

لمزيد من المعلومات: سياسة خصوصية Google

٣. Firebase Crashlytics (تقارير الأعطال)

يستخدم سكينة Firebase Crashlytics للإبلاغ التلقائي عن الأعطال:

  • نوع الجهاز وإصدار نظام التشغيل
  • سجلات الأعطال التقنية
  • إصدار التطبيق ورقم البناء

الغرض: اكتشاف أخطاء التطبيق وإصلاحها لتحسين الاستقرار.

لا يتم تضمين أي محتوى شخصي (إدخالات اليوميات، الأسماء، الأدعية) في تقارير الأعطال.

٤. Firebase Authentication (المصادقة)

يستخدم سكينة المصادقة المجهولة عبر Firebase:

  • يتم إنشاء معرّف مستخدم مجهول تلقائياً عند أول استخدام
  • لا حاجة لأي بيانات شخصية — لا اسم، لا بريد إلكتروني، لا كلمة مرور
  • المعرّف المجهول يُستخدم فقط لربط البيانات السحابية
  • اختياري: يمكنك لاحقاً إضافة بريد إلكتروني لمزامنة بياناتك بين أجهزة متعددة (طوعي)

٥. Cloud Firestore (النسخ الاحتياطي السحابي الاختياري)

بالإضافة إلى التخزين المحلي، يتم نسخ البيانات التالية احتياطياً بشكل آمن في السحابة (Google Cloud Firestore):

  • سجل الجلسات (معرّف البروتوكول، المشاعر، المدة)
  • إدخالات اليوميات (المشاعر، السؤال، النص)
  • التقدم (إجمالي الجلسات، السلسلة، توزيع المشاعر)
  • بيانات الملف الشخصي (الاسم، إعداد اللغة)

موقع التخزين: Google Cloud، منطقة الاتحاد الأوروبي.

الوصول: أنت وحدك من يمكنه الوصول إلى بياناتك (مؤمّنة بقواعد أمان Firebase).

إدخالات اليوميات لا يتم تحليلها أو تقييمها — فهي للتوثيق الشخصي فقط.

التطبيق يعمل بالكامل بدون اتصال سحابي. Firestore هو نسخ احتياطي إضافي فقط.

٦. لا إعلانات

سكينة لا يحتوي على إعلانات ولا أدوات إعلانية. لا يتم بيع البيانات لأطراف ثالثة.

٧. أمان البيانات

البيانات المحلية مُخزّنة على جهازك. البيانات السحابية تُنقل مُشفّرة (TLS) ومحمية في Google Cloud Firestore بقواعد أمان Firebase. فقط المستخدمون المُصادق عليهم يمكنهم قراءة وكتابة بياناتهم الخاصة.

٨. خصوصية الأطفال

سكينة لا يجمع عن علم بيانات من أطفال دون ١٣ عاماً. التطبيق لا يحتوي على تسجيل أو مشتريات داخلية أو إعلانات.

٩. حقوقك

يمكنك في أي وقت:

  • حذف جميع البيانات المحلية عبر الإعدادات → إعادة تعيين البيانات
  • إلغاء تثبيت التطبيق (يزيل جميع البيانات المحلية)
  • طلب حذف بياناتك السحابية عبر البريد الإلكتروني (انظر الاتصال)

١٠. التغييرات

عند إجراء تغييرات جوهرية على سياسة الخصوصية، سيتم إخطار المستخدمين من خلال تحديث التطبيق. النسخة الحالية متاحة دائماً على هذا الرابط.
